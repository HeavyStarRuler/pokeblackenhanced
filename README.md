# Pokémon Black Enhanced

## About

Pokémon Black Enhanced is an enhancement ROM hack for Pokémon Black Version to introduce following pokémon and some quality of life additions.

Included below are the basic details for all changes to the vanilla game made within this ROM hack separated into sections depending on what major area of the game the change affects most. Below this section (**About**), you will also find the [Table of Contents](https://github.com/HeavyStarRuler/pokeblackenhanced#table-of-contents).
